Unlock Your Encrypted MIUI Gallery Photos & Videos Offline

​MIUI Gallery Decryptor is a clean, privacy-focused Android utility designed to recover compatible .lsa (encrypted image) and .lsav (encrypted video) files created by MIUI Gallery's private album feature. Every step happens locally on your phone—no internet connection, account login, or cloud upload required.

​Key Features

​100% Offline AES-128-CTR Decryption: Processes .lsa full-stream photos and .lsav header-encrypted videos directly on your device without sending any data over the network. 

​Single & Batch File Recovery: Select a single file for instant preview or queue multiple .lsa and .lsav files to decrypt and export in one batch. 

​Interactive Queue Management: Review all selected files on the home screen with IMG/VID type badges and file sizes, add more files to the queue anytime, or remove individual files with a single tap (✕). 

​Automatic Format Detection (Magic Bytes): Inspects decrypted file headers to restore the exact original extension and MIME type automatically—supporting PNG, JPEG, GIF, BMP, TIFF, WebP, HEIC, MP4, MOV, M4V, MKV, AVI, and 3GP. 

​Built-In Media Preview & Player: Inspect decrypted photos with a full-screen pinch-to-zoom viewer and watch decrypted videos with the built-in video player before or after saving.

​Flexible Output Storage: Choose a dedicated output folder once for automatic batch saving, or use "Save As" to pick a custom location and filename for individual files.

​Minimal, Distraction-Free Interface: Built with a clean, flat layout with instant Dark and Light mode switching and zero ads or background trackers.

​How It Works

​Tap Select .lsa / .lsav Files to pick one or more encrypted MIUI Gallery files from your device storage.

​Tap Files path (CHANGE) to set your preferred output folder for decrypted media.

​Tap Decrypt File (or Decrypt All for batches) to restore your original photos and videos. 

​Preview your recovered media inside the app and save it directly to your storage.

​Privacy & Security

​Zero Data Collection: The app does not collect, transmit, or store personal data, photos, or videos on external servers.

​No Ads or Trackers: Contains no analytics SDKs, advertising networks, or background services.

​Authorized Use: Intended solely for recovering media files that you own or are legally authorized to access. Keep backups of your original files before processing.
